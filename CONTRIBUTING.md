# Contributing to dynavec

Thank you for your interest in contributing to dynavec!

Contributions are welcome, including bug fixes, improvements, documentation, tests, and new features.

## Before you start

For larger changes, please open or comment on an existing GitHub issue before starting implementation. This helps avoid duplicate work and gives maintainers an opportunity to discuss the proposed approach.

For smaller documentation fixes or bug fixes, first check that there is no existing work addressing the same problem.

## Development setup

dynavec supports Python 3.9 and newer.

The project uses `uv` for dependency and environment management.
